# azmaine.space

Static portfolio for Sayad Azmaine, served by GitHub Pages at https://azmaine.space.

- `/` — music persona (`index.html`)
- `/professional/` — research / content / marketing persona
- `assets/style.css` — shared; `body.music` / `body.pro` swap the colour tokens

No build step. Open `index.html` locally or run `python3 -m http.server`. Missing content is marked `TODO` in the HTML. Until it arrives the page says "Coming soon" instead of showing placeholder videos or tracks, and the stats row (videos, views, shows) stays out until each number has a source.
